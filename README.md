## Wi-Fi 7 Network Card Explorer

<sub>Disclaimer - Contains no proprietry data, only publicly available information.</sub>

### Purpose
To gain a deeper understanding of the entire flow of network data through a wifi-7 card. 

<hr>

### Content
It is a static page with 3 tabbed views. The original tool was created quickly with AI prompts to get the idea started. It has some minor imperfections but is generally working.
